# OICL AO PDF Desk

Simple reference tool for OICL Administrative Officer (Scale-I).

## Download PDFs

- 📚 5 Policy Wordings (Motor, Fire, Health, Misc, Aviation)
- 📄 5 Proposal Forms (Motor, Fire, Health, Misc, General)
- 📬 5 Claim Forms (Motor, Fire, Health, Misc, Checklist)

All links go to official OICL sources:
- Policies: https://orientalinsurance.org.in/download-policy-terms-conditions
- Forms: https://orientalinsurance.org.in/proposal-form
- Claims: https://orientalinsurance.org.in/claim-form
