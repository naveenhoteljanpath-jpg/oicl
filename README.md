# OICL AO Work Desk — Mobile PWA

A mobile-first static web app for an OICL Administrative Officer (Generalist).

## Publish on GitHub Pages

1. Create a GitHub repository, for example `oicl-ao-work-desk`.
2. Upload the contents of this folder to the repository's `main` branch.
3. Open **Settings → Pages** and select **GitHub Actions** as the source.
4. The included workflow deploys the site automatically.
5. Open the published HTTPS URL on Android Chrome.
6. Choose **Install app / Add to Home screen**.

## Security

This is a public static site. Do **not** put confidential OICL records, policyholder data, passwords, internal credentials, unpublished circulars, or restricted DOP material into the public repository.

The DOP section intentionally does not invent authority limits. Current authorised internal OICL DOP should only be added in an appropriately secured/private deployment.
