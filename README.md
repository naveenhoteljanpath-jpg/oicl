# OICL AO Work Desk — Mobile PWA

GitHub Pages-ready mobile web app for Prachi Tyagi, Administrative Officer (Scale-I), Generalist, OICL.

## Important document-link behaviour
- Policy wordings and proposal forms are linked to OICL's official public document libraries.
- Claim forms and claim-document guidance are linked to OICL's official claim-form/document pages.
- The app does **not** invent or hard-code unverified PDF URLs. OICL's public download pages are dynamic libraries; when OICL exposes a PDF, open/download it from the official OICL page.
- Official source links open in a new tab and are HTTPS links.

## GitHub Pages
Upload the contents of this folder to the repository root (so `index.html` is at the repository root), or use the included GitHub Actions workflow.
